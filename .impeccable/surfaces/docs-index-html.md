# Surface: docs/index.html

Mode: Persuade
Audience: poseur iPhone qui cherche un juge de ligne, pas un réseau social.
Job: comprendre Pose → Score → Lock en un viewport, croire que la vidéo ne part pas, accepter qu’il n’y a pas encore de bouton Store.
Action: aucune conversion réelle ; le CTA « Bientôt sur l’App Store » est un état, pas un lien.
Proof: splash réel, HUD rejoué, scores 62/91 étiquetés Exemple, trois faits on-device.
Constraints: identité de l’app, pas de social proof, pas de prix, Zyzz n’est pas un partenaire, GitHub Pages statique.

## Direction contract

THESIS: La page *est* le lock — une scène de gym éteinte et un score qui monte jusqu’au vert — pas une grille de features fitness.

OWN-WORLD: Quasi-noir de salle au repos, ivoire, or froid unique, vert lock / rouge cadre. Big Shoulders Display pour le tableau de juge ; Source Sans 3 pour lire. Grain, vignette, coins continus 16px sur le téléphone seulement.

STORY: Le visiteur sait que PoseLock note la pose sur l’iPhone, croit que la vidéo n’en sort jamais, et voit qu’il faudra attendre l’App Store.

FIRST VIEWPORT: Nav superposée, photo splash bord à bord, POSELOCK en bas à gauche, ligne « Pose. Score. Lock. », une phrase, CTA bientôt disabled. À droite le score-rouleau 87 puis LOCK. Un seul poster, pas de carte.

FORM: Page produit Apple (pin, scrub, un objet) + tableau de juge de scène. Signature : reel 0→87, hold 1,5 s, flash vert. Seed: brief-pinned, code-first, pas de concept-seed (demande précise).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
